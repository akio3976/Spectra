## 功能简介/Functions ##
Spectra 是一个基于可交互 HSV 图表的颜色管理工具。离线版本体仅100KB，单文件 HTML，完全免安装，打开即用。色板以 JSON 文件保存在本地。


## 开始使用/Start to Use ##
Spectra 在初次打开时会要求您新建一个色板。输入色板名称，然后选择色相分组预设或手动设置分段方案。创建色板后，您可在设置页再次调整。

界面底部和右侧颜色列表内均有添加颜色入口。打开添加颜色界面，图表中将出现一个预览点，并随着参数变化自动跳转。
确认添加后，颜色点会固定在图表中，并添加至颜色列表。

` ⚠添加颜色后，数据将暂时保存在浏览器的 localStorage 中，因此您无需在每次打开都重新导入色板。但这将导致在打开无痕模式、清除本地数据、切换浏览器的情况下，更新的数据无法被保存。要彻底保存，您需要将色板及时导出到本地。 `

您可点击左侧的标签在各分组间灵活跳转。

## 切换视图/Change Chart Mode ##
Spectra 提供了两种视图：色板视图和散点视图。点击顶部栏的“散点视图”按钮（移动端显示为圆圈图标灰色按钮），图表切换到散点视图，
此视图下仅显示颜色点位置，便于观察数据分布情况。色板视图下，点击颜色点会在详情栏内显示其信息和与之重叠的点。

## 技术规范/File Format ##
Spectra 的色板 JSON 文件采用如下的格式：

```
{
  "version": "1.0",
  "name": "未命名色板",
  "bounds": [345, 22, 60, 165, 210, 270],
  "groupTitles": ["红色组", "橙黄色组", "绿色组", "青蓝色组", "靛蓝色组", "紫色组"],
  "colors": [
    { "id": "1", "rgb": [225, 0, 0] },
    { "id": "2", "rgb": [32, 180, 255] }
  ]
}
```

## 兼容性/Compatibility ##
我们关注多种设备的交互体验。界面适应多种屏幕比例，在移动端也能流畅使用。

Spectra 能够兼容浮晓 Hxiao/青山公仔开发的“取色卡 (Color Card)”软件。设置页滑动到底部，点击“导出到取色卡”可保存兼容格式的 JSON 并导入到取色卡的“配色管理”界面。
